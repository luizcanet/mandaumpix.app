Sobre o Manda um PIX

mandaumpix.app • v1.0.0

Manda um PIX é um aplicativo web progressivo (PWA) gratuito que facilita a geração de cobranças via PIX sem a necessidade de ficar abrindo aplicativos de banco, com execução e armazenamento 100% locais no navegador.
